
# Game of Life Simulation

A browser-based implementation of Conway's Game of Life, developed
as part of my Video Game Design and Development studies.

## Overview

Conway's Game of Life is a cellular automaton in which cells evolve
over discrete generations according to a set of rules based on the
states of their neighbours.

This project explores how a simple set of rules can generate complex
patterns and emergent behaviour.

## Technical Focus

- JavaScript-based simulation logic
- Cellular automata and state transitions
- HTML and CSS for the browser interface
- Separation of application logic and presentation

## Technologies

- HTML5
- CSS3
- JavaScript
